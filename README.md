# 夜の予定表

18:00〜26:00 の予定を週単位で公開するカレンダーです。サーバーもAIも使わず、GitHub Pages だけで動きます。予定はリポジトリ内の `events.json` に保存します。

## ファイル

- `index.html` … カレンダー本体
- `events.json` … 予定データ（これを書き換えると公開内容が変わる）

## 公開手順

1. GitHub で新しいリポジトリを作る（Public）
2. `index.html` と `events.json` をアップロード
3. Settings → Pages → Branch を `main` / `/(root)` にして Save
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で表示される

このURLを共有すれば、相手は閲覧だけできます。

## 予定の追加・変更

1. 自分だけ `https://<ユーザー名>.github.io/<リポジトリ名>/?edit` を開く
2. 空いている時間をクリックして追加、予定をクリックして編集・削除
3. 上に出る「events.json を保存」でファイルを書き出す
4. GitHub のリポジトリで `events.json` を開き、書き出したファイルで差し替えて Commit
5. 1〜2分で共有URLにも反映される

編集中の変更はそのブラウザに一時保存されるので、途中で閉じても消えません。差し替えが終わったら「変更を破棄」を押すと下書きが消え、公開中の内容表示に戻ります。

`?edit` はパスワードではないので、知っている人なら誰でも編集画面を開けます。ただし変更は GitHub に Commit しない限り公開されないので、他の人が予定を書き換えることはできません。

## 時間の扱い

- 日付は「その夜の日付」です。10月21日の 25:00 は、10月22日の午前1時のことです
- 午前0時〜6時に開くと、前日の夜として「今」の線が表示されます

## events.json の形

```json
{
  "updatedAt": "2026-10-21T00:00:00.000Z",
  "events": [
    { "id": "a1", "title": "バイト", "date": "2026-10-21", "start": 60, "end": 300, "color": "teal", "memo": "" }
  ]
}
```

`start` / `end` は 18:00 からの分数です（60 = 19:00、300 = 23:00、480 = 26:00）。色は `indigo` `teal` `amber` `rose` `slate` から選べます。
